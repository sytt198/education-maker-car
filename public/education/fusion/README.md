# 教育版参数化 Fusion 重建包

解压后保留 EducationCar 文件夹完整。在 Fusion 的“实用工具 → 脚本和附加模块”中从设备添加该文件夹，运行 EducationCar。

脚本从同目录 project.json / recipe.json 读取当前网页参数与布局；step/ 内为原始教育版106个实际分件。默认90 / Ø40 / 10的配置逐件直接导入原实体。底盘加长时创建带随动孔位的新底板，保持原PCB安装柱位置；轮胎变大或变宽时只增加原轮外环，原轮毂、孔位、轴承座不缩放。

成功运行后在 output/ 写入 F3D、STEP 及运行报告。F3D 是在 Fusion 中生成的原生归档，不是在浏览器中凭空转换出来的。脚本新建设计，不覆盖当前文档。若运行失败，错误报告保留在包中，不会把部分结果标为完成。

参数在 Fusion 中登记；改变 project.json 后重新从网页导出匹配的 recipe.json，再运行脚本重建。直接修改导入零件的显示参数不会重建采购件。可变底盘和轮胎外圈有独立原生拉伸/切除特征。轮圈扩展与原轮圈在几何上相交，连接与最终布尔/导出需查看运行报告。

新配置的动态扫掠、结构强度、实物配合和线束未验收。基准V5验证报告不作为新配置的验证记录。
